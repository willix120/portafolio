gesden-api

API escrita en Go (Golang) para la Clínica Dental Manosalbas (Sevilla, España). Expone los endpoints que permiten interactuar con el sistema de gestión interno de la clínica, basado en el software GELITE (Gesden G5), y funciona como servicio para un chatbot: permite gestionar citas y disponibilidad entre otras operaciones. La API se conecta a la base de datos SQL Server de la clínica, incluye un mecanismo de seguridad interno que restringe el acceso únicamente a los sitios autorizados y se expone mediante un túnel seguro, ya que corre en el servidor local de la clínica.
